Gefälscht - German for "Fake". This is a fake website, created by Deque Systems, for use during training. Our clients are pointed to this site so that we can train them using an inaccessible site without having to point to the site of a real company. This site has a number of intentional accessibility problems. It is not an example of how to do things but rather how not to do them.
